The accompanying `hitchcock.conf` is the unmodified configuration member from this exact zip. It declares `DistributionLicense=Public Domain`; its About field independently says the dictionary "is out of copyright, so feel free to copy and distribute it". CrossWire's module page (https://www.crosswire.org/sword/modules/ModInfo.jsp?modName=Hitchcock, checked 2026-11-06) shows the same licence.

The text, from Hitchcock's New and Complete Analysis of the Holy Bible (late 1800s), is public domain. We use the CrossWire-hosted edition under its own notice, as for Easton's: CrossWire names CCEL as its upstream text source (`TextSource=CCEL`), but no CCEL-hosted file is downloaded. Software is not included or linked. The app's SWORD Import converts the TEI entries to plain text, one entry per name.
