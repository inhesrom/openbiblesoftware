# Interlinear lines fall back to a Strong's index built into the app

Interlinear lines (#143) on an English Bible with Strong's numbers read the Lemma and Gloss from the Bible's own tagging or from installed Lexicons. A library with only such a Bible (the BSB, KJV with Strong's) showed nothing but the numbers (#243). We decided that **the app carries its own Strong's index**: `crates/engine/assets/strongs/index.tsv` (about 700 KB, compiled in), one row per disambiguated Strong's number — number, first Hebrew or Greek form without accents, STEPBible's brief gloss — generated by `cargo xtask strongs-index` from the TBESH and TBESG files `starter/sources.toml` pins. A line reads the Bible's tagging, then the library's Lexicons in Preferred order, then this index.

## Considered Options

- **Only installed Lexicons, with a hint to install them:** the hint stays (for lines the index cannot fill), but a Bible's default lines would be empty on first use, the problem the ticket reports.
- **Look the Starter library's `tbesh`/`tbesg` `.obr` files up directly:** missing from an app without its Starter library, and a full Lexicon lookup per word where a 3-column table is enough.
- **Ship the whole TBESH/TBESG text:** larger, and TBESH's Meaning column needs Online Bible's permission (the Starter build skips it too); the index keeps only the number, lemma and gloss.

## Consequences

- The index is CC BY 4.0 data in the binary: `ATTRIBUTION.toml` credits it (Help → Credits, "Built into the app"), and its header names the sha256 of both inputs; a test fails when the lock pins other files, so a TBESH/TBESG update reruns `cargo xtask strongs-index`.
- A base number with several senses (H7225 "first: beginning", "first: best") takes the sense the English word uses, else the word the senses share; a gloss listing alternatives ("in/on/among") shows the one the English uses. This is display only: Word Study, Search and the Lexicons are unchanged.
- The index is not a Resource: it is not in the library, cannot be ranked, and an installed Lexicon always wins.
